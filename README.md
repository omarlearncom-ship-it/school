# مدرسه‌یار AI

سایت فارسی راست‌چین برای دستیار آموزشی با Groq API؛ شامل گفتگو، معلم خصوصی، حل مسائل، خلاصه‌سازی و آزمون چهارگزینه‌ای تعاملی با محاسبه نمره.

## اجرای محلی

نیازمندی: Node.js 18 یا جدیدتر.

1. پروژه را استخراج کن.
2. در ترمینال پوشه پروژه اجرا کن: `npm install`
3. فایل `.env.example` را به `.env` کپی/تغییرنام بده.
4. داخل `.env` کلید تازه Groq را در `GROQ_API_KEY` بگذار. کلید را در چت یا فایل‌های عمومی قرار نده.
5. اجرا کن: `npm start`
6. مرورگر: `http://localhost:3000`

مدل پیش‌فرض از متغیر `GROQ_MODEL` خوانده می‌شود. اگر مدل در حساب تو فعال نیست، نام یکی از مدل‌های موجود در کنسول Groq را قرار بده.

## انتشار رایگان با Render

1. یک مخزن GitHub بساز و فایل‌های پروژه را آپلود کن؛ `.env` را آپلود نکن.
2. در Render گزینه **New → Web Service** را انتخاب و مخزن را وصل کن.
3. تنظیمات: Build Command = `npm install` و Start Command = `npm start`؛ پلن Free را انتخاب کن.
4. در بخش Environment متغیر `GROQ_API_KEY` را با کلید تازه بساز. `GROQ_MODEL` را نیز در صورت نیاز اضافه کن.
5. Deploy را بزن. Render یک نشانی رایگان با دامنه `onrender.com` می‌دهد. سرویس رایگان ممکن است پس از بی‌کاری خاموش شود و اولین بازدید دوباره کمی طول بکشد.
6. دامنه اختصاصی معمولاً باید جداگانه خریداری شود؛ برای شروع مسابقه از نشانی رایگان Render استفاده کن.

## امنیت و محدودیت‌ها

- کلید فقط در سرور خوانده می‌شود؛ هرگز آن را در `public/app.js` یا GitHub قرار نده.
- `.env` در `.gitignore` قرار دارد. فقط `.env.example` بدون کلید واقعی قابل انتشار است.
- محدودکننده ساده درخواست برای جلوگیری از استفاده بیش از حد وجود دارد؛ این جایگزین محافظت حرفه‌ای و پایگاه داده محدودیت‌ها نیست.
- پاسخ‌های هوش مصنوعی ممکن است اشتباه باشند؛ قبل از ارائه به داوران همه ابزارها را آزمایش کن.
- این نسخه حساب کاربری و ذخیره‌سازی دائمی ندارد.
